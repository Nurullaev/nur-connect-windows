# Первая сборка Nur Connect для Windows

Версия: **0.1.0-pre.1+1**. Статус на 21 ноября 2026 года: проверки и сборка выполняются.

## Среда

Windows 11 Pro ARM64 в Parallels. Целевой первый пакет — Windows x64.
Flutter 3.47.6 (`5fc346839b5d0eef006ed8404392afb4dfae428d`), Dart 3.13.5,
Go 1.27.1, Rust 1.99.0 для native API, Visual Studio Build Tools 2022
17.14.45 / MSVC 14.44 / Windows SDK 10.0.26100.0, Inno Setup 6.7.4.

Анализатор: `flutter analyze --no-pub --no-fatal-infos` — **No issues found**.
Целевые проверки импорта, профиля/HWID, запуска, главной, серверов, настроек,
идентификаторов, About и обновлений прошли после исправлений. Основной прогон:
349 успешных, 1 платформенный skip и 1 устаревшее ожидание ключа upstream;
после его исправления тесты манифеста — 26/26, итоговый повтор packaging +
manifest с проверкой архитектуры SDK — 56/56. Полный набор всех тестов upstream
не запускался. Упаковка EXE/ZIP пока выполняется.

Для x64 нужен именно x64 Flutter/Dart SDK, даже на ARM64 Windows. Flutter
выбирает Windows target по ABI своего Dart и не поддерживает здесь параметр
`--target-platform`. Скрипт упаковки проверяет соответствие SDK и `--arch`,
чтобы случайно не назвать ARM64-сборку x64.

## Ограничения предварительного выпуска

- Иконки временно унаследованы из FlClashX по решению владельца.
- Authenticode и собственные ключи обновлений ещё не настроены. Provider-signed
  обновления без нашего доверенного ключа отклоняются.
- GitHub Actions форка отключены; upstream CI не используется для наших выпусков.
- Настоящая подписка, HWID, TUN/прокси и подключение к VPN требуют отдельной
  проверки на изолированном QA-профиле. Тесты используют фикстуры.
- Обычная Windows x64, установка рядом с FlClashX, автозапуск, сон/смена сети,
  обновление и удаление ещё не прошли полную приёмку.

## Выдача подписки

Windows UA: `Nur-Connect-Windows/v0.1.0-pre.1 core/v1.19.34 Platform/windows`.
В панели добавлено отдельное правило **Nur Connect Windows** после мобильных
клиентов, перед остальными Mihomo. Оно выбирает MIHOMO, не меняя HWID или шаблон
выдачи. Реальные пользовательские подписки для проверки этого этапа не запрашивались.
