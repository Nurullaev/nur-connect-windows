# Обновления Nur Connect для Windows

Новая установка включает автоматическую проверку версий. Сохранённый выбор
пользователя «выключено» не меняется. Переключатель и ручная проверка находятся
в настройках Windows; ручная проверка также доступна в «О приложении».

Приложение проверяет версии после инициализации, затем раз в 6 часов, пока оно
работает. Возврат в окно тоже запускает проверку, если срок подошёл. Ошибка сети
даёт повтор через 30 минут (таймер проверяет срок каждые 5 минут). Одновременные
проверки и окна объединяются. Если новая версия найдена в трее, окно показывается.

Диалог предлагает **Обновить** и **Позже**. «Позже» закрывает окно, а не скрывает
версию навсегда. Установленная через EXE копия скачивает установщик, проверяет
SHA-256 и идентичность, затем предлагает установку. Portable-копия открывает
страницу выпуска для ручной замены. Обновление не устанавливается без действия
пользователя; действуют прежние ограничения safe mode и смены подключения.

## Источник и каналы

Windows проверяет только `Nurullaev/nur-connect-windows` на GitHub. Заголовки
`flclashx-update` и `flclashx-update-pre` подписки не заменяют этот источник.
Upstream ключ обновлений не используется. Проверки HTTPS, хешей и идентичности
из базы сохранены. Authenticode собственного выпуска ещё не настроен.

Обычная версия (с `1.0.0`) получает только обычные выпуски без суффикса и без
отметки pre-release. Копия «Nur Connect Pre» (`0.1.0-pre.*`) получает только
pre-выпуски. Это разные программы с разными каталогами данных; автоматического
перехода между ними нет: на обычную версию переходят установкой 1.0.0 и удалением Pre.

## Как выпустить следующую версию

1. Изменить `pubspec.yaml`, например на `1.0.1+13` (pre: `1.1.0-pre.1+14`).
2. Собрать и проверить через `dart setup.dart windows --env stable --arch amd64`
   (для pre — `--env pre`)
   с x64 Flutter/Dart SDK, C++/CMake/Windows SDK/ATL и Inno Setup 6.
3. Сохранить соответствующие исходники в GitHub и создать Release на их коммите.
   Тег должен совпадать с версией приложения без build suffix:
   `v1.0.1` (обычный выпуск, Latest) или `v1.1.0-pre.1` с отметкой **pre-release**.
4. Приложить `NurConnect-windows-amd64-setup.exe` и
   `NurConnect-windows-amd64-setup.exe.sha256`. Скрипт сборки создаёт sidecar
   автоматически. Без него загрузка обновления отклоняется.
5. Также приложить ZIP с его `.sha256` и соответствующий архив исходников.
   Проверить digest загруженных файлов. Не переиспользовать тег для другой версии.

Actions форка пока отключены, публикация выпуска выполняется отдельно.
Наличие нового коммита без Release и файлов не означает доступное обновление.

Проверки выполняются на фикстурах: расписание/повтор/занятость, сохранение выбора,
кнопки диалога, источник GitHub, хеши и installer handoff. Сквозная замена установленной
версии проверяется при следующем реальном выпуске; фиктивные новые версии в
публичном репозитории для теста не публикуются.
