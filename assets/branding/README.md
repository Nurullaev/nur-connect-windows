# Nur Connect brand asset

The owner supplied the NurConnect VPN Figma design:
https://www.figma.com/design/NPrYOqgoklecBOkjaUVolm/NurConnect-VPN?node-id=138-2199

The online logo page was reviewed on 2026-11-21. The navy square, gold N and
blue orbit variant matches the original 512px application artwork already held
in the owner’s nurconnect.org website materials (Apple app ID 6832267202).
`nur-connect-original.jpg` is that original file, copied without visual changes.
It was not reconstructed from a screenshot or generated.

`assets/images/icon.png` is a PNG conversion. The two application ICO files
contain PNG images at 16, 20, 24, 32, 40, 48, 64, 128 and 256px. They were made
with macOS sips resizing and standard ICO packaging, without retouching.
These files brand the Windows executable, installer and About image.
Upstream functional connection-status tray symbols remain for this preview.
The mobile and Windows products continue to be independent projects.
